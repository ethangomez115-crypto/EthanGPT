## Description (paste into the itch.io description box)

Nexus AI is an original, privacy-first AI assistant that runs on your Android phone or desktop. It ships with a small built-in language model, so it works with no internet and no account.

WHY NEXUS AI
- Fully free and open source. No subscription, no ads, no telemetry.
- No API keys bundled in the download. Your keys (if you add any) stay on your device.
- Offline by default: the built-in model answers without sending anything anywhere.
- Optional online mode: add your own free key from Groq, OpenRouter, Gemini or DeepSeek for stronger answers.

FEATURES
- Chat with conversation history
- Interactive replies: select text, copy, save to a file, or share
- Keyless image generation from a text prompt — save, share or open the result
- Save and share files and images to WhatsApp, email, or cloud drive
- Back up chats to a file that survives app reinstalls
- Terminal and Code IDE tabs
- Local website preview (loopback-only) and Code IDE connected to chat
- Swipe in from the right edge on any tab to open the Code IDE; left edge opens the menu
- Clean code editor to view and edit code like Google AI Studio (Copy / Preview / Ask Nexus)
- Real WebView browser with "Open in browser" and "Share link"
- Works on low-RAM phones (auto-switches to online mode below 8 GB RAM)
- Desktop app for Windows, Linux and macOS (Java 11+)

DOWNLOADS
- Android: Nexus-AI-v15.3.apk (Android 8.0+, install from unknown sources)
- Desktop: Nexus-AI-Desktop-v15.3.zip (unzip, run java -jar nexus-ai.jar)
