EthanGPT is a tiny language model that you can build yourself on a phone.
EthanGPT uses a tokenizer to turn text into numbers.
The tokenizer turns words into tokens and tokens into numbers.
The numbers go into a language model that predicts the next token.
A language model learns patterns from text by reading many examples.
Q: What is EthanGPT?
A: EthanGPT is a small language model built from scratch in Python.
Q: What is a token?
A: A token is a small piece of text, such as a character or part of a word.
Q: What is a vocabulary?
A: A vocabulary is the list of all tokens and their integer ids.
Q: How does a tokenizer work?
A: A tokenizer splits text into tokens and maps each token to an id.
Q: Can the model run offline?
A: Yes, the offline model runs on your phone without internet.
Q: Does EthanGPT need a GPU?
A: No, EthanGPT is designed for a phone CPU with only NumPy.
Q: How much RAM does EthanGPT need?
A: A tiny model needs less than one gigabyte of free RAM.
Q: What is BPE?
A: BPE stands for byte pair encoding and it merges frequent pairs of characters.
Q: What does encode mean?
A: Encode means converting text into a list of number ids.
Q: What does decode mean?
A: Decode means converting number ids back into readable text.
Q: What is temperature?
A: Temperature controls how random the generated text will be.
Q: What is top-k sampling?
A: Top-k sampling keeps only the k most likely next tokens.
Q: What is top-p sampling?
A: Top-p sampling keeps tokens whose total probability reaches p.
Q: Where are checkpoints saved?
A: Checkpoints are saved in the checkpoints folder.
Q: Can training continue later?
A: Yes, load a checkpoint and continue training from it.
Q: What is a transformer?
A: A transformer is a neural network that uses self attention.
Q: What is self attention?
A: Self attention lets each token look at earlier tokens in the sequence.
Q: What is an embedding?
A: An embedding is a vector that represents the meaning of a token id.
Q: What is a chat interface?
A: A chat interface lets you type messages and read replies.
Q: Can EthanGPT help with coding ideas?
A: It can suggest simple ideas, but it is not a trained coding assistant.
Q: Can EthanGPT connect to the browser?
A: Yes, browser mode opens a web page with your question.
Q: Which AI can EthanGPT use?
A: It can use a local model, Open Code, Ollama, or a browser page.
Q: Is Open Code free?
A: Open Code is open source, but some providers behind it may charge.
Q: How do I install Python on Android?
A: Install Termux from F-Droid and run pkg install python.
Q: How do I install NumPy?
A: Run pkg install numpy inside Termux.
Q: How do I run the tokenizer test?
A: Run python tokenizer/test_tokenizer.py from the project folder.
Q: How do I start the chat?
A: Run python main.py chat from the project folder.
Q: How do I start the local server?
A: Run python main.py serve and open the app or a browser.
